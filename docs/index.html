What is VeriCapture?

VeriCapture is a media verification dApp for the Solana Seeker phone. It creates immutable, timestamped proofs of your photos and videos using the Solana blockchain. Two-stage hash chain verification — Stage 1 commits the content hash on-chain, Stage 2 commits the sealed hash for tamper detection.

Important: VeriCapture never uploads your media files. Only SHA-256 hashes are submitted to the blockchain. Your photos and videos remain on your device at all times.

Features

Two-Stage Hashing

Stage 1 commits the content hash on-chain. Stage 2 seals and verifies for tamper detection. Double proof for maximum integrity.

Blockchain Proof

Records SHA-256 hashes on the Solana blockchain via the Memo Program as immutable, timestamped proof of media authenticity.

SGT Free Access

Saga Genesis Token (SGT) holders get unlimited free hash recording. Others pay per hash via SOL or SKR.

Seeker Integration

Sign In With Solana, Mobile Wallet Adapter (MWA), and native Seeker device integration.

Important Notice

VeriCapture creates cryptographic proof that a specific media file existed in a specific form at a specific time. It does not upload, transmit, or store your media files on any server or blockchain. Only SHA-256 hashes are recorded on-chain. These hashes are irreversible — the original file cannot be reconstructed from the hash. On-chain hashes are immutable and cannot be deleted once recorded.
